Morphe JSON → MPP

Paste a patches-bundle.json, a link to one, a GitHub/GitLab repository, or a Morphe Manager settings export. You get the .mpp patch bundle plus ready-made links for Morphe Desktop and Morphe Android.

Input

Converts automatically. Paste JSON, or a link to a JSON file on GitHub, GitLab, Codeberg, a Gist, jsDelivr or any site that allows it. You can also drop a .json file here.

    🖥 Morphe Desktop command

    Patches one app with all the selected sources in a single run. Desktop downloads each source's latest .mpp itself. Replace your_app.apk with your APK.

    📦 Or merge them into one .mpp

    Get the selected download links, copy them or download files individually, then drop the files into Merge .mpp files below. Getting links does not start any downloads.

    For JDownloader, use Copy for JDownloader and paste into Add New Links. These links use directhttp:// to treat each URL as a file instead of scanning a web page.

    Suggested filenames use author-repo-version-XX.mpp, where XX is the JSON version. Cross-site downloads may keep the server's filename; use the name shown here when saving.
